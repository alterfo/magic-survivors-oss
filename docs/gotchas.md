# Грабли и решения

- **Мобы замирали после склейки меша.** Исходные рендереры выключены → Animator с `CullUpdateTransforms` не считал кости. Решение: `AlwaysAnimate` + ручное выключение аниматора у мобов вне кадра (с запасом по краям).
- **В сборке пропадали земля и декор**, а персонажи были видны. GPU Resident Drawer выкидывал варианты шейдеров при сборке. Выключен в `Assets/Settings/PC_RPAsset.asset`.
- **Модули Web/Windows** не ставятся через Hub CLI (редактор не из Hub). Ставили распаковкой pkg с `download.unity3d.com/download_unity/3ff58d469c8a/MacEditorTargetInstaller/` в `PlaybackEngines`, затем перезапуск редактора — без него сборка «Succeeded», но файлов нет.
- **Unity CLI**: MagicSurvivors — порт 7801 (7800 — Platformer). `capture_game_view` без `--source camera`, иначе нет GUI. Приватные поля в eval — через рефлексию.
- **Отложенные вызовы** (`EditorApplication.delayCall`) не срабатывают, пока редактор без фокуса.
- **Шрифты**: в Russo One и Philosopher нет →, −, ∞ — капс-плашки на Fira Sans, минус пишем «-».
- **Текст «двоился»** от длинных диагональных теней — тень только вниз и короткая.
- **Настройки графики** меняются на копии URP-ассета (`Instantiate`), иначе в редакторе перезаписывается файл проекта.
- **Шляпа мага шире тела** — коллизия с декором радиусом 0.65, а не 0.4.
- **Хук dcg** блокирует `>` в системные пути (в т.ч. по ssh) — конфиги пишем локально и копируем `scp`.
- **Сундуки и реликвии в зданиях.** Точка спавна бралась случайной и попадала внутрь склепа. Теперь `World.Free(p, rad)` выталкивает её из твёрдого декора; считает по периодической решётке декора, потому что вдали от мага предметы ещё не перенесены (`Follow`).
- **curl с этого мака до игрового сервера** висит через `HTTPS_PROXY` — проверять прод с `curl --noproxy '*'`.
